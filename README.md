# 🧙‍♂️ Mestre do Tempo

App completo para dominar seu **tempo**, **corpo** e **mente**. Feito em HTML, CSS e JavaScript puro — sem dependências.

## ✨ Funcionalidades
- 🕐 Relógio em tempo real
- ⏱️ Cronômetro com voltas
- ⏳ Timer regressivo
- 🏃 HIIT/Sprint com voz e ciclos
- ⏰ Despertador
- 🌍 Relógio mundial
- 🏋️ Planejador de **Treinos** (30+ esportes)
- 📚 Planejador de **Estudos** (matérias + 15 idiomas)
- 📅 Calendário de progresso
- 🔥 Ofensiva (streak) com recorde
- 📊 Estatísticas mensais separadas
